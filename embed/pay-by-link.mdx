---
title: "Create and send Pay by Link payment requests"
description: "Create a Pay by Link payment request via API or Backoffice and send customers a URL to complete payment on Paybyrd's hosted checkout."
---

Pay by Link generates a URL that your customer can open to complete a payment on Paybyrd's hosted checkout page. You can deliver the link over SMS, email, or any other channel — or let Paybyrd send it automatically when you provide the customer's contact details.

<Info>
  You can create payment links in three ways: via the API, through the Paybyrd Backoffice, or directly from a Paybyrd POS terminal.
</Info>

## Create a payment link via API

Send a `POST` request to the Pay by Link endpoint. Use the sandbox URL during development and the production URL when you go live.

| Environment | Endpoint |
|-------------|----------|
| Sandbox | `https://gatewaysandbox.paybyrd.com/api/v2/paybylink` |
| Production | `https://gateway.paybyrd.com/api/v2/paybylink` |

### Request fields

<ParamField path="Amount" type="string" required>
  The payment amount as a decimal string (e.g. `"10.00"`).
</ParamField>

<ParamField path="SellerEmailAddress" type="string" required>
  Your merchant email address.
</ParamField>

<ParamField path="OrderRef" type="string" required>
  Your internal reference for this payment.
</ParamField>

<ParamField path="ShopperEmailAddress" type="string">
  Customer email address. When provided, Paybyrd automatically sends the link by email.
</ParamField>

<ParamField path="ShopperFirstName" type="string">
  Customer first name.
</ParamField>

<ParamField path="ShopperLastName" type="string">
  Customer last name.
</ParamField>

<ParamField path="ShopperPhoneNumber" type="string">
  Customer phone number. When provided, Paybyrd automatically sends the link by SMS.
</ParamField>

<ParamField path="Culture" type="string">
  BCP 47 locale code for the checkout language (e.g. `"en-US"`).
</ParamField>

<ParamField path="ExpiresIn" type="integer">
  Number of hours until the link expires.
</ParamField>

### Example request

```bash
curl --request POST 'https://gatewaysandbox.paybyrd.com/api/v2/paybylink' \
  --header 'Content-Type: application/json' \
  --header 'x-api-key: <YOUR_API_KEY>' \
  --data '{
    "Amount": "10.00",
    "SellerEmailAddress": "[email protected]",
    "OrderRef": "ABC12345",
    "ShopperEmailAddress": "[email protected]",
    "ShopperFirstName": "John",
    "ShopperLastName": "Test",
    "ShopperPhoneNumber": "",
    "Culture": "en-US",
    "ExpiresIn": 24
  }'
```

### Response fields

<ResponseField name="paybyLink" type="string">
  The payment URL to share with your customer.
</ResponseField>

<ResponseField name="transactionId" type="string">
  The Paybyrd transaction ID associated with this payment link.
</ResponseField>

```json
{
  "paybyLink": "https://gateway.paybyrd.com/en-US/hostedform?paymentId=ad4293ed-7055-48b2-8bc5-2efaa4fdd34d",
  "transactionId": "ad4293ed-7055-48b2-8bc5-2efaa4fdd34d"
}
```

If you provided `ShopperEmailAddress` or `ShopperPhoneNumber`, Paybyrd sends the link automatically. Otherwise, share the `paybyLink` URL with your customer through your own channel.

## Create a payment link via Backoffice

<Steps>
  <Step title="Open the Pay by Link menu">
    Log in to the Paybyrd Backoffice and click **Pay by link** in the sidebar.
  </Step>
  <Step title="Fill in the payment details">
    Complete the form with the payment amount, order reference, and customer contact information.
  </Step>
  <Step title="Send the link">
    Click **Send link**. Paybyrd sends the link to the customer's email address or phone number based on the information you provided.
  </Step>
</Steps>

## Customise the link message

The SMS and email message that accompanies your payment link can be customised to match your brand. Messages can be up to 1,000 characters long.

To set up a custom message, email [email protected] with your preferred text. Paybyrd supports the following languages: PT, ES, FR, DE, EN, and NL.
